# 16 Week Project Plan

| Week | Phase | Deliverable |
| --- | --- | --- |
| 1 | Literature Review | Study web testing, Playwright, AI-assisted testing, FastAPI |
| 2 | Requirement Analysis | Finalize scope, problem statement, objectives |
| 3 | System Design | Architecture, data flow, module separation |
| 4 | Database Design | Test case and test run schema |
| 5 | Backend Setup | FastAPI app, configuration, health endpoint |
| 6 | API Development | Test case, run, analytics endpoints |
| 7 | AI Generation | Natural language to structured test steps |
| 8 | Fallback Logic | Rule-based planner for offline model mode |
| 9 | Playwright Integration | Browser launch, navigation, screenshot capture |
| 10 | Execution Engine | Step runner, error handling, status classification |
| 11 | Frontend Dashboard | Form, generated steps, run panel |
| 12 | Analytics Dashboard | Run counts, pass rate, recent history |
| 13 | Testing | Pytest suite and manual browser checks |
| 14 | Documentation | README, architecture, API, user manual |
| 15 | Viva Preparation | Presentation, Q&A, demo flow |
| 16 | Final Review | Cleanup, verification, final submission |
